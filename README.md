# customersuccess.cx proof of concept

A proof of concept for moving [customersuccess.cx](https://www.customersuccess.cx) off Squarespace
onto a static site that Claude Code can maintain from plain files: two pages and two Support Stack
episodes, built with Astro and deployed to GitHub Pages.

Live at https://conorpendergrast.github.io/customersuccess-cx/

See `CLAUDE.md` for how to add an episode or a page.
